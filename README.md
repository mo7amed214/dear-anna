# Dear Anna

A short epistolary narrative prototype set in Stanislav's room in Saint Petersburg, 1905, during Bloody Sunday.

## Requirements

This project is run by **Unity 6000.6.2f1**.

## Running the project

1. Clone or download this repository.
2. Open it as a project in Unity (matching version above recommended).
3. Open `Assets/Scenes/SampleScene.unity`.
4. Press Play.
